# Alarms — 社内お知らせ掲示板

## 方針

アラート/通知（ページング、メール、Slack 連携等）は本スコープ外。ローカル・単一利用者・お試し用途のため、常時監視と通知の仕組みは設けない。 [observability-requirements]

## 現状の代替

- 異常は実行中のコンソールログに WARN として現れる（検証失敗・未検出）。致命的な障害はアプリ停止として現れる。
- 将来運用に移行する場合は、エラー率などに対するアラートしきい値を SLO 違反の手前に設定することを検討する（スコープ外）。
