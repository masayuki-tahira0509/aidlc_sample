# Wireframes — 社内お知らせ掲示板

ロー・ファイデリティ（ラフ）のワイヤーフレーム。2画面構成。 [Q1]

## 画面1: お知らせ一覧画面

一覧画面。登録済みのお知らせを新しい順に表示し、各行から編集・削除ができる。上部に新規作成ボタン。 [Q1] [Q2]

```
┌──────────────────────────────────────────────┐
│  📢 お知らせ掲示板                [ + 新規作成 ] │
├──────────────────────────────────────────────┤
│  システムメンテナンスのお知らせ                  │
│  投稿者: 山田太郎   2026-10-07 10:30            │
│  サーバーメンテナンスを実施します…               │
│                              [ 編集 ] [ 削除 ]  │
├──────────────────────────────────────────────┤
│  歓迎会のご案内                                 │
│  投稿者: 鈴木花子   2026-10-06 15:00            │
│  来週金曜に歓迎会を開催します…                   │
│                              [ 編集 ] [ 削除 ]  │
├──────────────────────────────────────────────┤
│  （お知らせがない場合）                          │
│  まだお知らせはありません。                      │
└──────────────────────────────────────────────┘
```

**要素:**
- ページタイトル「お知らせ掲示板」
- 「新規作成」ボタン → 作成フォーム画面へ遷移
- お知らせカード（タイトル・投稿者名・投稿日時・本文プレビュー）
- 各カードに「編集」「削除」ボタン
- 空状態メッセージ

## 画面2: お知らせ作成/編集フォーム画面

新規作成と編集を兼ねるフォーム。タイトル・投稿者名・本文を入力。 [Q1] [Q2]

```
┌──────────────────────────────────────────────┐
│  お知らせ作成               ( 編集時は「お知らせ編集」) │
├──────────────────────────────────────────────┤
│  タイトル                                       │
│  [ _______________________________________ ]  │
│                                                │
│  投稿者名                                       │
│  [ _______________________________________ ]  │
│                                                │
│  本文                                           │
│  [ _______________________________________ ]  │
│  [ _______________________________________ ]  │
│  [ _______________________________________ ]  │
│                                                │
│                      [ 保存 ]   [ キャンセル ]   │
└──────────────────────────────────────────────┘
```

**要素:**
- タイトル入力欄（単一行、必須）
- 投稿者名入力欄（単一行）
- 本文入力欄（複数行テキストエリア）
- 「保存」ボタン → 一覧画面へ戻る
- 「キャンセル」ボタン → 保存せず一覧画面へ戻る
- 編集時は既存値がプリフィルされる

## データ項目（お知らせ）

| 項目 | 型 | 説明 | Source |
|------|----|------|--------|
| タイトル | テキスト | お知らせの見出し（必須） | [Q2] |
| 本文 | テキスト（長文） | お知らせの内容 | [Q2] |
| 投稿者名 | テキスト | 投稿者の名前（認証なしのため手入力） | [Q2] |
| 投稿日時 | 日時 | 作成時に自動記録 | [Q2] |

## Assumptions & Open Questions

- [assumption] 高忠実度のビジュアルデザイン（配色・フォント・余白）は Refined Mockups で詰める。
- [assumption] レスポンシブ対応（モバイル表示）は MVP では必須としない。
