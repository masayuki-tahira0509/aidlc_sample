# SLO Config — 社内お知らせ掲示板

## 方針

SLI/SLO/SLA は設定しない。性能は厳密な基準値ではなく緩やかな努力目標とする方針（学習・お試し用途、合否を縛らない）であり、可用性目標も設けない。 [observability-requirements][project.md Corrections]

## 現状の扱い

- 性能の目安（努力目標）は `performance-requirements.md` に記載済み（一覧1秒・保存500ms 等。合否基準ではない）。
- 将来運用に移行する場合は、具体的なパーセンタイル・時間窓付きの SLO（例: 99.9% / 30日ローリング）を定義することを検討する（スコープ外）。
