# Anomaly Config — 社内お知らせ掲示板

## 方針

異常検知（メトリクスの自動異常検知、機械学習ベースの検知等）は本スコープ外。ローカル・単一利用者・お試し用途のため、常時メトリクス収集を行わず、異常検知の基盤も設けない。 [observability-requirements]

## 現状の代替

- 異常は実行中のコンソールログ（WARN）および例外として現れ、開発者が目視で把握する。
- 将来運用に移行する場合は、メトリクス収集を前提とした異常検知の導入を検討する（スコープ外）。
